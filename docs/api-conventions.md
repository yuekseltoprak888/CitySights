# API conventions

- Prefix: `/api/v1`
- JSON requests and responses
- Assessment routes live under `/api/v1/organizations/{organization_id}/assessments`
- Errors use one body: `code`, `message`, `details`, `request_id`
- Error responses omit stack traces
- List endpoints use cursor pagination. `limit` is from 1 to 100
- Timestamps are UTC ISO-8601
- Quantities are objects: `{ "value": "1200.0", "unit": "kWh" }`
- `GET /api/v1/health` returns 200 when PostgreSQL and PostGIS are reachable, and 503 when they are not
- OpenAPI is generated by FastAPI at `/openapi.json`
- Clients send `X-Request-Id` when they have one. The API returns the same header

Create requests that fail validation return `422` and `code` `validation_error`. An unknown assessment inside a known organization returns `404` and `code` `assessment_not_found`.
